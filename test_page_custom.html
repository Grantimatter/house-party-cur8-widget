🎭 Cur8 Custom Events Widget

Fully customizable event display with descriptions and advanced features

Default Layout

💡 This widget fetches events from the Cur8 public API and displays them with full descriptions, venue information, and direct ticket purchase links.

How to Use

📖 The widget is completely decoupled from the official cur8-widget.js script. It uses the same public API endpoints but provides full customization.

Basic Usage:

<!-- Load the custom widget script --> <script src="cur8-custom-widget-enhanced.js"></script> <!-- Load the stylesheet --> <link rel="stylesheet" href="cur8-widget.css"> <!-- Create a container --> <div id="my-events"></div> <!-- Initialize the widget --> <script> const widget = new CustomCur8Widget(23121, 'my-events'); widget.load(); </script>

With Options:

const widget = new CustomCur8Widget(23121, 'my-events', { showDescription: true, showVenue: true, showPricing: true, showDates: true, sortByDate: true, dateFormat: 'LLLL', // requires moment.js ticketDomain: 'https://cur8.com' }); widget.load();

Configuration Options:

showDescription (boolean) - Display event descriptions [default: true]
showVenue (boolean) - Display venue information [default: true]
showPricing (boolean) - Display pricing options [default: true]
showDates (boolean) - Display event dates [default: true]
sortByDate (boolean) - Sort events by earliest date [default: true]
dateFormat (string) - Moment.js date format [default: 'LLLL']
ticketDomain (string) - URL for ticket links [default: 'https://cur8.com']

Customization

🎨 The widget uses BEM-style CSS classes, making it easy to customize. All styles are in cur8-widget.css

Common CSS Classes:

.cur8-custom-wrapper - Main container (grid layout)
.cur8-custom-event - Individual event card
.cur8-custom-event-image - Event poster image
.cur8-custom-event-title - Event name/title
.cur8-custom-event-description - Event description
.cur8-custom-event-venue - Venue information
.cur8-custom-event-pricing - Pricing options
.cur8-custom-button-primary - Ticket purchase button

Example: Custom Colors

<style> /* Change button color */ .cur8-custom-button-primary { background: #ff6b6b; } .cur8-custom-button-primary:hover { background: #cc5555; } /* Change event card background */ .cur8-custom-event { background: #f9f9f9; border: 1px solid #e0e0e0; } /* Adjust grid layout */ .cur8-custom-wrapper { grid-template-columns: repeat(2, 1fr); } </style>
