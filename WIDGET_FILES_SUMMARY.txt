USAGE SUMMARY
=============

To use this widget on Squarespace:

1. Create a new page titled "event" (URL: /event)

2. Upload CSS and JS files to your server/CDN
   - Get the URLs where you upload them

3. Add Code Injection (Squarespace settings):
   <link rel="stylesheet" href="https://your-url/cur8-event-detail-page.css">
   <script src="https://your-url/cur8-event-detail-page.js"></script>

4. Add Code Block to the page:
   <div id="cur8-event-detail"></div>

5. Link to events:
   https://yoursite.com/event?event=23121

That's it! Users will see the full event details.

DEPLOYMENT STEPS
================

1. Get the files from this project:
   • cur8-event-detail-page.js
   • cur8-event-detail-page.css

2. Upload to your server/CDN
   (Get the full URLs where uploaded)

3. In Squarespace, go to:
   Settings → Advanced → Code Injection → Header

4. Add this code:
   <link rel="stylesheet" href="https://your-cdn/cur8-event-detail-page.css">
   <script src="https://your-cdn/cur8-event-detail-page.js"></script>

5. Create new page "event" in Squarespace

6. Add Code Block to page with:
   <div id="cur8-event-detail"></div>

7. Save and test with: /event?event=23121

8. Create links to events: /event?event=<event_id>

CUSTOMIZATION EXAMPLES
======================

Change primary color:
  Edit in cur8-event-detail-page.css:
  --cur8-primary: #your-color;

Change text color:
  Edit in cur8-event-detail-page.css:
  --cur8-text-primary: #your-text-color;

Change container ID:
  In HTML: <div id="my-container"></div>
  In JS: containerId: 'my-container'

Change API endpoint:
  In JS constructor:
  apiUrl: 'https://your-api.com/events'
